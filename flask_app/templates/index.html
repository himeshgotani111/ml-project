    System Pipeline Architecture

    End-to-end data processing, feature engineering, model training, and REST API deployment.

    STEP 01
    Data Ingestion

    Handled 70,000 raw patient records, identified physiological BP anomalies and verified 50-50 target balance.

    STEP 02
    Outlier Filtering

    Filtered ap_hi > ap_lo, removed impossible body metrics, computed BMI, and standardized features.

    STEP 03
    Scratch Baseline

    Implemented Logistic Regression from pure NumPy (Sigmoid, Log Loss, Gradient Descent) without Sklearn.

    STEP 04
    Hyperparameter Tuning

    Tuned Random Forest via GridSearchCV across 5-Folds to achieve 0.8012 ROC-AUC.

    STEP 05
    API Deployment

    Serialized models via Joblib with CORS-enabled JSON endpoints for seamless client integration.
